# MemGarden v0.1.0

The first tagged release, and the state of the system after its cutover: v1 acceptance criteria met, the legacy Python system shut down on 2026-08-21, and this daemon the only memory system wired to Claude Code on the machine it was built on.

## What it is

A local memory system for Claude Code, in one Rust daemon over one SQLite file:

- **Capture** through four Claude Code hooks (`SessionStart`, `UserPromptSubmit`, `Stop`, `SessionEnd`) at **0.85 ms per turn**; the transcript is the spool, so a daemon that is down loses nothing — the next hook or the next session's catch-up posts the delta again.
- **Extraction** by a local Ollama model (`qwen3-14b`, a 16 GB card; 12 GB with a Q5 quant — the 8 GB option was measured and rejected) into facts with time, entities and provenance; `<private>` sections never reach the model.
- **Recall** in about **7 ms**: FTS5 BM25 + sqlite-vec KNN + graph + temporal arms, RRF-fused, under a token budget, with retracted and expired facts filtered in one place.
- **Consolidation** of facts into observations and mental models, with a task ledger per bank (written, not yet injected).
- **A web UI** (dashboard, WebGL memory graph, ledger views) and lock-free metrics (88 ns per request).

## What is measured, not claimed

- Recall quality against a frozen 2,718-fact corpus and 20 graded queries (`gold/results.jsonl`, 16 rows); the blind-panel parity judgement that gated the cutover was 12 better / 4 worse / 4 equivalent.
- A substitution experiment (MX-3) in which memory **lost** 11–7 on questions whose answers were already in the repo — recorded, not hidden. The value measured so far is retrieval, not storage.
- Distillation is worth +27 % recall@10; the embedded reranker ships **off** because it cost recall@10.

## Operating it

- `scripts/deploy.sh` from a checkout, or `memgarden self-update` from this release: both back up before a schema change, install both binaries, restart under a systemd **socket** unit (a restart never refuses a hook — measured 0 refused in 219 probes), and verify by build identity.
- `memgardend --version` prints version, build and schema; `/healthz` reports `build`; `memgarden hooks status` says whether the hook binary and the daemon match.
- A binary older than the database refuses to start, naming the backup to restore.

## Requirements

Linux x86_64 (this asset), Rust 1.95 to build from source, Ollama with an extraction model, systemd `--user` for the units (optional; the daemon runs from a terminal too).

## Known limits

- One target in this release. Other targets build from source.
- The task ledger accumulates rows and nothing reads them yet; automatic retraction detection found 2 of 3 targets and 22 false positives and ships off.
- The backup-before-migration path has not yet been exercised by a real schema bump; the first `v14` migration is its first live test.
